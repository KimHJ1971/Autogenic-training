# 🌙 자율훈련법 편안한 음성안내 (Autogenic Training)

> **플라우드(Plaud) 녹음 전사본의 실천 지침과 요하네스 슐츠(J.H. Schultz)의 정통 6단계 공식**을 결합한, 누워서 듣는 음성 가이드 PWA 웹 애플리케이션입니다.

🌐 **웹앱 바로가기 (GitHub Pages)**: [https://KimHJ1971.github.io/autogenic-training/](https://KimHJ1971.github.io/autogenic-training/)

---

## ✨ 주요 기능

- 🎙️ **친절한 한국어 음성 안내 (TTS)**: 차분한 0.82x 템포의 부드러운 목소리와 문장 간 5~8초의 넉넉한 묵상 침묵
- 🎶 **432Hz 힐링 사운드 신시사이저**: Web Audio API로 실시간 합성되는 432Hz 이완음, 6Hz 세타파, 핑크 노이즈 밤바람, 티베트 싱잉볼 타종
- 🌙 **OLED 트루 블랙 암전 모드**: 침대에 누웠을 때 눈부심을 완전히 없애주는 칠흑(#000000) 화면 모드
- 🛡️ **화면 꺼짐 방지 (Wake Lock)**: 가이드를 듣는 동안 스마트폰 화면이 꺼져 오디오가 끊기지 않도록 방지
- 🌗 **2가지 마무리 모드**:
  - **수면 유도 모드**: 소거 동작 없이 포근한 온기 속에서 그대로 숙면으로 이행
  - **일상 복귀 모드**: 3단계 정통 소거 동작(주먹 쥐기 · 팔 굽히기 · 심호흡 후 눈 뜨기)으로 활력 충전
- ⏱️ **3가지 코스 프리셋**:
  - **⚡ 1~2분 퀵 코스**: 플라우드 전사본 권장 핵심 요약 (휴식 시간 3~4분 이내)
  - **🌿 3~5분 표준 정통 코스**: 슐츠 박사의 정통 6단계 풀코스
  - **🌌 8~10분 심층 수면 코스**: 각 단계마다 3회 이상의 심호흡과 깊은 묵상
- 📱 **크롬 PWA 앱 설치 지원**: 브라우저 주소창이나 메뉴에서 **[앱 설치]** 또는 **[홈 화면에 추가]**를 눌러 독립 앱으로 사용 가능

---

## 🏛️ 정통 6단계 공식 체계

1. **준비단계 (배경 공식)**: "마음이 차분해지고 있다. 평온한 햇살이 가득한 초원에 편안하게 누워 있다."
2. **제1단계 (중량감 / 무게감)**: "양팔과 양다리가 아주 무겁다" (골격근 이완)
3. **제2단계 (온열감 / 따뜻함)**: "양팔과 양다리가 아주 따뜻하다" (말초혈관 확장, 혈류 촉진)
4. **제3단계 (심장 조정)**: "심장이 조용하고 규칙적으로 뛰고 있다" (심장 자율신경 안정)
5. **제4단계 (호흡 조정)**: "숨이 저절로 쉬어진다 / 호흡이 지극히 편안하다" (자연스러운 숨)
6. **제5단계 (복부 온열)**: "배가 따뜻하다 / 명치 부위가 따뜻하다" (태양신경총 및 내장 이완)
7. **제6단계 (두부 냉감)**: "이마가 시원하다 / 머리가 맑고 쾌적하다" (두한족열, 잡념 해소)

---

## 📲 크롬에서 앱으로 설치하는 방법

1. 스마트폰이나 PC 크롬(Chrome) 브라우저에서 배포 주소에 접속합니다.
2. 주소창 우측의 **[설치] 아이콘** 또는 우측 상단 메뉴(⋮)에서 **[홈 화면에 추가]** 또는 **[앱 설치]**를 터치합니다.
3. 바탕화면 또는 홈 화면에 생성된 **'자율훈련법'** 아이콘을 누르면 앱처럼 풀스크린으로 실행됩니다.
